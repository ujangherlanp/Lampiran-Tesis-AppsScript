# Lampiran-Tesis-AppsScript
Source code aplikasi Apps Script Tesis

# Judul Tesis: PENGEMBANGAN PERANGKAT PEMBELAJARAN BLENDED LEARNING TERINTEGRASI ADAPTIVE SCAFFOLDING BERORIENTASI PADA PEMAHAMAN KONSEP DAN KEMANDIRIAN BELAJAR SISWA

Repositori ini berisi *source code* yang digunakan dalam pengembangan website untuk penelitian tesis.

## Daftar File
*   **Kode.js**: Berisi fungsi *back-end* Google Apps Script untuk memproses data dari *spreadsheet*.
*   **Index.html**: Berisi tampilan *front-end* (UI) aplikasi yang digunakan oleh siswa maupun peneliti.
*   **History.js**: Berisi fungsi kustom (*custom function*) `PARSE_PROGRESS_LOGS` untuk Google Sheets. Fungsi ini bertugas membaca sel yang berisi data riwayat/log berformat JSON panjang, lalu memecahnya menjadi format tabel matriks agar mudah dihitung dan dianalisis di *spreadsheet*.
